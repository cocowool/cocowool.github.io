Mac环境下配置Tomcat+Eclipse

更新于：2026-08-10 19:59:05 发布于：2017-09-28 11:02:00

下载Tomcat

首先在Tomcat官方网站找到自己合适的版本，下载 tar.gz 版本的，下载完成后解压缩到一个目录，进入这个目录下的 bin 执行 startup.sh，如果看到下面的界面，表示已经启动了。

打开浏览器，输入http://localhost:8080能够看到界面显示，表示安装已经成功了。

我使用的是7.0.81的版本，最新的版本是9。

配置Eclipse

启动Eclipse后，选择 Preferences(快捷键⌘+,)

选择 Server->Runtime Environments，点击 Add 添加

选择合适的Tomcat版本，点击下一步，然后找到自己刚才下载的Tomcat位置，点击完成。

今后新建了项目之后，就可以运行在这个Server上进行预览测试了。

我使用的是 Eclipse Oxygen
