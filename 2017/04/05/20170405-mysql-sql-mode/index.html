ERROR 1690 Out-of-Range

当Mysql中的数字字段存储了一个超过允许范围的数字时，会触发1690 Out of Range错误，是否触发错误取决于SQL运行时的模式：

当标准 Standar Mode 或 Strict Mode 运行时，数据插入会失败
当非限制模式 No Restrictive 运行时，Mysql将数值转化为范围允许内的最大或最小值进行存储
