Sqlmap 介绍

更新于：2026-08-11 13:40:24 发布于：2024-01-12 08:12:19

Sqlmap 是检测服务端是否存在SQL注入漏洞的自动化工具。因为其强大的检测能力，常用在CTF比赛的SQL注入类型的题目中。它的主要功能是扫描、发现并利用指定URL中的SQL注入漏洞，支持的数据库类型非常多。

安装

在 macOS 中，可以通过 brew install sqlmap 安装并通过命令行使用。
